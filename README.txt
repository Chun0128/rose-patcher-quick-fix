Rose Patcher Quick Fix v1.3 — Clean package / 精簡包

繁體中文
1. 先安裝 Rose 與 7-Zip：https://www.7-zip.org/
2. 將 ZIP 全部解壓縮，結束對局後雙擊 FIX_NOW.cmd，允許管理員提示。
3. Rose 重新開啟後，進訓練模式確認造型。
需要還原：雙擊 RESTORE.cmd。還原只恢復修復前的檔案，不保證能使用造型。

English
1. Install Rose and 7-Zip: https://www.7-zip.org/
2. Extract the whole ZIP. Finish your match, run FIX_NOW_EN.cmd, and approve the administrator prompt.
3. After Rose restarts, test the skin in Practice Tool.
Undo: run RESTORE_EN.cmd. This restores the previous files, which may still have the original problem.

請保留這 9 個檔案在同一資料夾；只複製 CMD 無法使用。
Keep all 9 files together; the CMD launchers need the three PowerShell scripts.

本工具下載官方 LTK 1.29.1 配套檔案，驗證雜湊與簽章，並先備份再更換。
Downloads the official signed LTK 1.29.1 pair, verifies hashes/signatures, and backs up before replacement.
備份 / Backups: %LOCALAPPDATA%\RosePatcherFix\backups

僅適用支援範圍內的遊戲建置；上限 2026-11-01 07:00 UTC（台灣 15:00）。
Game executable build limit: 2026-11-01 07:00 UTC. This is not your computer's current time.
遊戲更新後可能失效。Later game updates may require a different compatible patcher.
