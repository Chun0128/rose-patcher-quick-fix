Rose 補丁相容性工具 v1.3 — 官方 LTK 1.29.1

目前狀態：2026-10-31 已在本機 Rose 1.4.9 的訓練模式確認布里茨造型生效，使用者也已確認成功。
雙擊 FIX_NOW.cmd。
工具會先確認沒有對局，核對官方檔案、自動關閉 Rose、備份、更換兩個檔案，再重新開啟 Rose。
目前檔案已正確且 Rose 正在執行時，會顯示不必重複替換。
Windows 詢問管理員權限時，請確認執行的是此工具。完成後進訓練模式確認。
正在對局中時工具會停止，不會強制關閉遊戲。
RESTORE.cmd 可還原最近一次備份並重新開啟 Rose；還原只是恢復修復前的檔案，不保證能使用造型。
START.cmd 提供手動檢查、套用與還原選單。原檔備份位於 %LOCALAPPDATA%\RosePatcherFix\backups。

本版下載官方 1.29.1 安裝包，只提取兩個原始簽章檔案，不安裝或降版 LTK Manager。
需要已安裝 7-Zip。檔案 SHA-256 與 Natoken LLC 簽章不符就會停止。
遊戲執行檔的建置時間必須不晚於 2026-11-01 15:00（台灣時間）；遊戲更新後可能失效。
這是建置日期上限，不是電腦時間的倒數；請勿更改電腦時間。
v1.2 的新版 stable DLL 已實測遭 host 驗證拒絕，勿再重複套用。
請保留本資料夾的所有檔案；只複製 CMD 檔無法使用。
